Integritetspolicy

För appen ”Du kör för fort, IDIOT!” (se.dettmansfixeri.dukorforfort). Senast uppdaterad 19 november 2026.

Kort version

Appen samlar inte in, sparar inte och säljer inte några uppgifter om dig. Det finns inga konton, ingen reklam och ingen spårning.

Platsdata

Appen använder telefonens GPS för att räkna ut din hastighet och för att ta reda på vilken hastighetsgräns som gäller där du är. Det sker bara medan appen är öppen på skärmen.

För att hämta hastighetsgränsen skickar appen din position (koordinater) till vår server på dukorforfort.dettmansfixeri.se. Servern frågar i sin tur Trafikverkets öppna API (api.trafikinfo.trafikverket.se) vilken hastighetsgräns som gäller på platsen och skickar svaret tillbaka till appen. Positionen skickas utan namn eller andra uppgifter om vem du är. Läs om hur Trafikverket hanterar personuppgifter på trafikverket.se.

Varken appen eller vår server sparar din position. Servern skickar bara frågan vidare och glömmer den sedan.

Som alla webbservrar kan vår server tillfälligt logga tekniska uppgifter som IP-adress och tidpunkt för anropet. Positionen ingår inte i de loggarna.

Behörigheter

  • Plats – för hastighet och hastighetsgräns.
  • Internet – för att fråga Trafikverkets API.

Barn

Appen riktar sig inte till barn och samlar inte in uppgifter från någon.

Ändringar

Om policyn ändras publiceras den nya versionen på den här sidan.
